# 管理员 Bots 生命周期与归属分配第一版规划

日期：2026-10-13。需求条目 BOT-ADMIN-LIFECYCLE-001；本轮任务 BOT-ADMIN-LIFECYCLE-PROTOTYPE-20261013。状态：规划与合成原型，真实实现待启动。服务端 Bots 控制台为平台管理员入口；客户端个人网络使用仍在现有 Agent Net，未来名 Bots Net。

## 范围与归属

管理员在明确纳管范围内新建、配置、启停、逻辑删除Bot，并分配所属用户和运行Host。Bot是稳定的管理对象，不以名称或Host地址作为身份；与真实Agent、工作区、Session、执行实例的映射在开发前由既有owner裁决，本次不创建新线协议或后台控制通道。

所属用户回答“这个Bot由谁负责、以谁的能力与预算边界供给”；实际发起者、审批者、执行身份、Host运营者分别记录。分配不自动授予目标用户Host OS权限，也不自动转移原用户私人会话、记忆、文件、连接器或凭据。受平台生命周期授权纳管的Bot才能更改所属用户；私人本地Bot和跨实例所有权转移仍不进入这一机制。

新建要求平台已有“代表所属用户创建”的授权、目标用户有效、目标Host纳管、目标用户在Host有Bot部署/运行权、Runtime和模型配置引用可用，以及预算在已经批准的能力包内。平台管理员管理Bot的权限不能替代Host部署权或擅自变更付费来源。

## 平台权限点

| 权限点（设计名称） | 允许的动作 | 前提与边界 |
| --- | --- | --- |
| bot.create | 为指定用户创建纳管Bot | 创建代理授权、用户/Host配对与预算有效；默认停止、共享关闭 |
| bot.configure | 修改名称、描述、Runtime、模型配置引用、指令与额度 | 执行配置需停止后更新，受用户能力/预算上限限制；只引用凭据 |
| bot.start / bot.stop | 启停指定Bot的接入及执行实例 | 目标Bot及Host的运行授权；停止不关整台Host，不影响其他Bots |
| bot.assign_owner | 重新分配纳管Bot所属用户 | 独立高风险权限、停止已确认、新用户有部署权；显式影响确认 |
| bot.assign_host | 更换纳管Bot运行Host | 源实例停止已确认、目标Host授权与能力有效；独立于归属变更 |
| bot.delete / bot.restore | 逻辑删除及恢复管理对象 | 停止已确认，名称确认、保留审计；恢复不自动启用或恢复共享 |

上述名称是待实现的权限模型，不是现有API。共享管理员、协作者、普通使用者不因共享角色得到这些平台权限；所有者通过个人端管理自有Bot也需要对应运行/部署权。PlatformAdminGrant绑定实例、纳管范围、动作和有效期，每次后端操作与Host执行均复核。

## 配置模型

配置包含稳定Bot ID、名称与描述、所属主体、目标Host ID、Runtime类型、模型配置引用、系统指令、明确资源/工具能力上限、日总额度和版本。模型引用不能显示/导出原始密钥，切换Host或所属用户后旧引用默认不可沿用。私有资源不随配置更改进入可共享范围；新增工具和资源仍需单独授权。

运行配置、共享授权、运行意图、当前执行实例分别持有修订号。审批与调用绑定有效Bot、配置版本、授权版本、执行身份及实例代次；名称不是权限标识。开发时复用既有成熟版本/幂等机制，不能靠UI状态完成一致性控制。

原型配置字段为名称、描述、Runtime、模型引用、系统指令和日总额度。1000–1000000 Token为演示校验区间，不是商业额度、计价或正式平台策略。系统指令可留空保存停止草稿，但执行配置标为待补全，启动前须填写；运行状态与配置完整性分别显示，重置与首次加载采用一致的初始化。必填字段缺失、重名、非有限值/非整数、额度低于已用与有效预留、超用户预算或Host能力均拒绝保存。取消不写入，失败保留草稿，成功回显当前配置和审计。

## 生命周期与状态

| 状态/操作 | 系统含义 | 界面与调用行为 |
| --- | --- | --- |
| 新建/待配置 | 管理对象已登记；未自动启动或共享 | 查看目录与详情，补配置后才可启动 |
| 已停止 | 目标Bot准入关闭，执行端已确认停止 | 不接新任务/共享写入；本人历史可读，其他Bot与Host正常 |
| 启动 | 配置、授权、Host能力与当前修订校验通过 | 在线才确认运行；不得用请求已发送冒充已运行 |
| 运行中 | 当前实例确认执行配置生效 | 按当前共享授权接受调用；配置版本不回写历史Session |
| 停止/停用 | 先关闭新准入，再按策略排空/取消该Bot执行 | 旧审批失效且预留释放；已结算用量不回滚 |
| Host离线/未知 | 无法确认当前执行端状态 | 可关闭新准入，但显示停止待确认/运行未知，不宣称进程停止成功 |
| 逻辑删除 | 管理对象进入回收站，路由与调用失效 | 默认目录隐藏、共享撤销；保留审计和本人历史成果 |
| 恢复 | 恢复管理记录，不恢复外部权限或运行实例 | 默认停止且共享关闭，重新校验配置与Host再启动 |

Bot启动/停止与暂停/恢复网络共享相互独立。启动不会自动恢复暂停共享；暂停共享不会停止Bot或整台Host。停止、执行配置改变、归属分配和删除均使不匹配旧请求、审批及订阅失效，重新启动不复活旧审批。

真实执行端返回未确认或超时只能标为未知，按同一操作ID查询与恢复，不生成新操作重复执行。停止回执属于Bot运行实例owner；不能把终止本地浏览器状态、关闭页面或中继连接当作停止Host进程。

## 用户与Host分配

1. 管理员打开Bot分配页，查看当前归属、Host及原→新摘要。运行中拒绝变更，先停止并取得源执行端确认。
2. 选择已注册且有效的目标用户、在线纳管Host，校验该用户Bot部署授权、Runtime/模型可用性、工作区隔离、目标预算和平台管理范围。第一版不对离线或未知源/目标执行端直接迁移。
3. 变化需确认原共享授权/邀请撤销、待审批失效及预留释放、共享关闭、资源范围重置、执行引用清空待重配；未变更则不写入、不增加版本或失效权限。
4. 保留Bot ID及历史审计，但新归属不能读取原发起者私人Session和成果。资源范围只能采用目标用户已经声明的公开模板/授权上限；原私人文件与凭据不搬移，跨用户数据迁移未来单独设计和授权。
5. 元数据更新、旧路由注销、源实例释放和目标准备需有可恢复的操作记录，拒绝两个Host同时运行同一逻辑Bot。完成分配保持停止/待配置，再补目标执行配置并显式启动。

原型使用三个合成Host：CN-East-01在线，四注册用户均有部署权，Builtin/Codex；Office-02在线，仅林沐和陈序有部署权，Builtin/Codex；CN-West-03离线，仅许知有部署权，Builtin。它们是示例权限矩阵，不代表真实Host资产或部署能力。

## 删除与恢复

本版“删除Bot”为逻辑删除，不是永久清除私人数据或删除Host。要求先停止并确认，显示对象、所属用户、Host和授权/任务影响，以完整Bot名称确认；取消和错误名称不删除。回收站保留管理对象和审计，撤销共享与邀请，废止旧审批并释放未消耗预留；已结算用量与本人成果不随删除清零。

恢复不自动复活共享、模型/连接器权限或旧审批，保持停止状态。真实实现需校验同名冲突、Host权限、配置版本及归属，重新授权后才能调用。本轮无永久清除入口；正式保留期、删除Host文件的授权与恢复窗口需后续单独确定。管理员不能通过恢复取得原私人上下文。

## 原型与后续验收

原型位于 [管理员Bots管理](../../../dev-docs/prototypes/agentnets-bot-sharing-v1/index.html)，具体设计约定、独立验收与执行记录见该目录LIFECYCLE-*文件。模拟状态与账号不证明真实认证、Host执行或后端持久化。预期可演示：新建→配置→启动→停止→分配→重配→启动→停止→删除→回收站恢复，跨页核对状态和审计。

- [ ] 真实平台权限点与“代表用户创建/部署”授权落实，普通共享角色不能越权。
- [ ] 配置/运行/归属修订与幂等持久化；双Host运行防护，源/目标不确定回执恢复。
- [ ] 停止阻断新调用并撤销旧请求，取消/排空策略和预留结算一致，其他Bot/Host不受影响。
- [ ] 归属变化后真实Session、记忆、向量、文件、浏览器、凭据和下载隔离不泄露。
- [ ] 逻辑删除、保留期、恢复、旧路由/凭证失效和审计授权通过多账号真实路径验证。
- [ ] 真实实现、模拟、联调、主干、发布及生产路径验收分开完成。
