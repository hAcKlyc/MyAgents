Status vocabulary:
- `fixed` — bug fixed, commit pushed, issue closed
- `not-a-bug-closed` — judged non-bug, replied + closed
- `cross-bugfix-failed` — bug fix bailed mid-flight, needs human
- `reviewed-notified` — feat/需求 analyzed + maintainer notified, awaiting decision
- `answered` — objective product question answered + closed
- `escalated` — non-codebase question forwarded to maintainer
- `auto-closed` — spam auto-closed
