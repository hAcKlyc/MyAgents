# Agent companion portraits

Nine AI-generated abstract companions selected in the 2026-10-31 design review.
These are optional identities alongside the existing vector glyphs, not a new
default. Each is an opaque square with its own background; `WorkspaceIcon`
applies the rounded crop at the requested size.

Production files are 128 × 128 PNG, resized from the reviewed 1254 × 1254
originals with Lanczos3 and lossless PNG encoding. This covers the current
14–44px display range at 2× density; all nine together are about 105 KiB.
No tracing, generative redrawing, or palette conversion was applied.

Source review package: `lively-private-nine-v1` in this chat's generated images
(the name reflects the earlier private-contact exploration, before the user
assigned these characters to Agent identities).
