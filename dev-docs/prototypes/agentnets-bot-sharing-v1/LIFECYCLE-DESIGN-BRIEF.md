# 管理员 Bot 生命周期扩展约定

任务 BOT-ADMIN-LIFECYCLE-PROTOTYPE-20261013。2026-10-13 用户要求补齐新建、配置、启停、删除及所属用户/Host分配；仅原型与规划。沿用已接受的管理员视觉与Bots Net次级用户入口，真实API、Host、模型、凭据、客户端和生产均不改。

## 代表页与入口

目录新增“新建 Bot”主动作。详情提供“配置”“分配用户与 Host”“启动/停止”和次级“删除 Bot”，不把所有动作塞进主顶栏。至少保留5个种子Bots与原共享流程。新建表单是代表页：基础信息、所属用户、目标Host、执行配置、保存为停止状态的摘要；先主审看该页再扩展后续模式。1440×900、768×1024、390×844，既有模拟标识、Tab/ShiftTab/Escape/焦点恢复都保留。

## 可操作范围与接口约定

1. **新建**：名称(必填、trim、1–60字、当前实例非删除Bot重名拒绝)、描述、所属注册用户(周予安/林沐/陈序/许知，不含访客)、纳管Host、Runtime(Builtin/Codex)、模型配置引用(两项明确模拟配置)、系统指令（可留空保存停止草稿，启动前须补齐并明确配置待补全）、Bot日总额度(有限整数1000–1000000)。默认共享关闭，创建后“已停止”，不自动启动。表单缺项/错误不保存，取消不新增；创建后的目录计数、详情、Host列表与用户归属统计一致，刷新保留。
2. **配置**：同类基础/执行字段可查看编辑，归属分配单独操作；停止后才能保存执行配置，运行中明确提示先停止。配置版本递增，相关旧审批失效并释放预留；不得凭模型引用展示原始凭据，不编辑所有者私人记忆。财务待配置Bot可经配置变为已停止，再启动。额度不得低于已用量与有效预留。
3. **启停**：Bot启停与“暂停共享”分开。启动需完整配置、有效所属用户部署授权、目标Host在线且Runtime兼容，保存状态并记审计；失败可恢复说明、不改变状态。停止阻断此Bot的新任务和共享资料写入，旧待审批失效释放预留，保留已得成果、授权和其他Bot/Host状态；重新启动不会恢复旧审批。离线时停用准入可立即生效，但显示“Host离线，停止待确认/运行状态未知”，不能伪称Host已确认停止；离线不能启动。
4. **分配用户/Host**：同一模态成对显示原→新所属用户与Host，仅停止且已确认停止的Bot可保存。演示部署授权：CN-East-01在线，4个注册用户均允许，Builtin/Codex；Office-02在线，仅林沐/陈序允许，Builtin/Codex；CN-West-03离线，仅许知允许，Builtin。离线/不兼容/无该用户部署授权的目标不可提交，明确原因。平台纳管权不授予任意Host管理权。新建也遵循该配对规则。
   - 修改归属或Host必须确认可见影响：原共享授权与邀请撤销、旧审批失效释放预留、共享关闭；资源范围重置为新归属的公开模板上限、模型引用和执行指令清空为待配置。私人会话、记忆、凭据和目录不迁移；历史成果仍按原发起者只读保留，不能转给新所属用户。仅纳管Bot可以这样分配，不代表允许接管私人Bot。无变化不写、不失效。
5. **删除**：必须先停止；删除模态显示Bot/用户/Host、授权和待审影响，输入完整Bot名称确认，取消不删除。本轮逻辑删除到回收站，不删除Host/用户/历史审计或私人成果；撤销共享和邀请、废止旧审批，不能启动或发新任务。目录默认隐藏已删对象，统计同步；回收站可恢复为停止且共享关闭状态，授权不自动恢复，历史审计保留。不提供永久清除。离线且停止未确认不可删除。
6. **共享回归**：所有受保护handler都检查Bot运行状态、删除标记及当前授权/资源/Host，不能只隐藏控件。暂停共享不改变运行状态；停止Bot不关Host，启动Bot不自动恢复暂停共享。Bot与原调用者ID保持稳定；配置、运行、归属修订/删除使旧请求不能执行。管理员与用户页、审批、用量审计保持同对象状态。

## 原型实现与证据边界

首次加载和重置必须采用同一生命周期归一化，种子运行Bot正常可用，财务Bot停止且执行配置待补全。已结算用量/历史包含回收站保留，若统计仅限在用对象须明确标签。既有V2本地状态保留，使用独立V3 key或明确可兼容迁移；不清除旧key和其他站点数据。状态全为合成；已有结果是模拟，不迁移真实文件/连接器。无新增CDN或API。主Agent写规划、Git及本设计；sharing_prototype只写index.html(必要时app.js/styles.css)。sharing_ui_review只读实现，拥有LIFECYCLE-UI-REVIEW.md和evidence/lifecycle-*（ESM .mjs，不用require），独立headless上下文，不动主浏览器。不得再派子agent，不操作Git/生产或其他工作树。

## 验收矩阵

| 角色/任务 | 本轮要求 | 验收动作 |
| --- | --- | --- |
| 平台管理员新建/配置 | 可操作 | 缺项、重名、非法额度、取消；新建→刷新→改配置→版本和审计 |
| 平台管理员启停 | 可操作 | 停止→用户任务/资料拒绝→Host与其他Bot不变→启动；离线拒绝且状态可信 |
| 平台管理员分配 | 可操作 | 运行中拒绝、非法用户Host配对拒绝、有效分配→共享/审批失效→待配置→重配→启动 |
| 平台管理员删除/恢复 | 可操作 | 名称校验、取消、停止前阻断、回收站与刷新、恢复不复活共享、跨页计数 |
| Bots Net被分享用户 | 授权内模拟 | 原邀请→接受→普通/高成本审批；Bot停止/迁移/删除后新调用拒绝、本人历史保留 |
| Host执行端 | 未接真实接口 | 只显示模拟结果或离线未知，不把本地状态称作进程/部署成功 |
| 视觉/响应式/键盘 | 分别验收 | 目录+表单+详情+回收站，三个视口，Tab/ShiftTab/Escape与焦点 |

参考流程是官方文档阅读，非登录实测：Portainer目录→新建/配置→详情操作及删除确认，Dify应用信息编辑与删除影响说明。MoXBots的停止默认、成对部署授权、逻辑删除/恢复及私人数据不转移是本项目设计选择，不声称对标产品具备同样机制。参考来源详见未来规划说明。
