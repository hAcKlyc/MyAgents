# MoXBots 平台管理员 Bots 管理原型约定

任务：AN-SHARE-PROTOTYPE-20261013。用户于 2026-10-13 纠正方向：主界面必须是服务端平台管理员的 Bots 管理，不是个人管理自有 Bot。个人使用与跨设备协作位于客户端网络入口，现有 Agent Net 后续规划更名为 Bots Net。本次仅规划和交互原型，不改真实客户端或服务。

## 主入口与视觉

默认进入“Bots 管理控制台”，当前身份固定为“平台管理员 · 当前实例”。主画面用 Bots 目录/表格承载多用户管理：Bot 名称、所有者、运行 Host、可用状态、共享状态、成员数与用量。所有统计从合成数据计算，不展示未经验证的真实监控。至少 5 个 Bots、3 个不同所有者、2 个不同 Host，能搜索名称/所有者，按状态或 Host 筛选。

左导航为“Bots”“Hosts”“用户与权限”“操作审批”“用量与审计”。Bots 是默认核心页；其他入口至少能展示和管理与本次 Bot 共享直接相关的信息，避免扩成无关控制台。没有实作的接入/真实监控操作须禁用并解释，不伪造成功。

选择 Bot 打开右侧详情或详情页，保持列表上下文。包括概览、共享成员与权限、授权资料与工具、额度和审批策略、审计元数据。签名细节是可读的共享范围预览与跨用户授权关系，而不是个人身份菜单。

沿用 specs/DESIGN.md 的阅读优先、状态可信和克制原则；浅色产品表面、清晰分隔，MoxBots 蓝色作为本原型 accent。Logo 复用 assets/moxbots-icon.png，不重绘。正文16px、控件14px、辅助12px、标题28px。1440×900、768×1024、390×844 三视口不横溢；表格可局部滚动或转换卡片，抽屉可滚动，手机导航折叠。

## 管理边界和角色

平台管理员是服务端治理身份，独立于 Bot 所有者和 Bot 共享管理员。可在当前实例的明确管理范围内查看不同用户已纳管 Bots 的元数据，配置共享关系、资源上限内授权、额度、审批与共享暂停。不能自动取得私人会话正文、原始凭据或 Host OS 权限，也不能将未纳管的本地私人 Bots 自动收归管理。

Bot 所有者保持原所有权并声明可共享能力/资源上限；平台管理员只能在这些上限及平台策略内配置。Bot 共享管理员只管理所属 Bot 的被委派低级成员，不能跨 Bot 管理、给自己扩权或更改总预算。使用者/协作者角色仍遵循规划矩阵。

合成对象建议：客户研究 Bot（周予安/云 Host，有共享）、项目交付 Bot（林沐/办公 Host，无共享）、资料整理 Bot（陈序/云 Host）、财务核对 Bot（陈序/办公 Host，资源上限受限）、会议摘要 Bot（许知/云 Host，Host 离线或共享暂停）。所有名称和数字为演示数据。

## 管理员主路径

1. 进入 Bots 全局目录，搜索或筛选跨不同所有者 Bots，打开目标 Bot 详情。
2. 管理共享：邀请指定用户，配置角色、允许资料、有效期、日额度和单次审批阈值；摘要即时更新，校验缺目标/空资源/重复邀请/额度。
3. 在成员列表编辑既有授权的角色、资源和额度；保存更新授权版本与审计，废止不匹配待审批。角色能力由 grant 决定，不能硬编码特定人名。
4. 管理审批：明确显示调用者、Bot、资源、执行身份、费用归属、预计用量、授权版本。批准后才模拟执行；拒绝/过期/重复处理不执行。
5. 暂停该 Bot 的网络共享或撤销某位成员授权，影响该 Bot 的后续调用；不假装停止 Host 进程。其他 Bots 不受影响。
6. 查看 Bot/全局用量与审计，查询主体、Bot 和事件一致；只记录操作元数据，不把他人私人会话正文作为审计内容。

资源受限 Bot 必须出现明确拒绝：管理员不能把声明为不可分享的私人目录或原始凭据加入授权。Host 离线、额度不足和授权过期有明确状态与恢复方式。各 Bot 设置独立保存，切换后不串用。

## 次级 Bots Net 用户体验

在主界面提供明确的次级“体验用户视角”入口（弹窗/独立视图），标为“Bots Net 用户端模拟”，不把个人身份切换放在主顶栏作为主入口。可切换林沐、陈序、许知及未授权访客来验证本次共享的实际结果；有“返回管理员控制台”。

用户路径：目标账号接受邀请 → 共享给我查看授权 Bot → 发起独立会话 → 普通任务5k Token模拟消耗或深度研究35k进入审批 → 返回管理员审批 → 用户看到结果/用量 → 撤销后不能再发任务。协作者只能维护授权资料；共享管理员可管理低级成员，不能升权、改总预算或看其他 Bots。

会话按 Bot+发起者隔离；管理员默认不读其正文。所有数据仅在本原型专用 localStorage 保存，模拟角色切换不等于真实认证。提供重置演示，不清理其他站点数据。

## 行为与技术约束

统一前端状态支持跨 Bot、跨页、模拟角色和刷新恢复。所有 handler 再检查角色、grant、Bot状态、资源范围、授权版本及额度，不只隐藏按钮。审批前预占用量，防止多个待审任务透支，重复提交不产生重复审批；授权变更/撤销/暂停后不能批准旧任务。只模拟，不真实调用API/模型/外发。

所有有意义按钮有可见结果；输入转义。dialog支持Tab/Shift+Tab圈定、Escape关闭及返回触发点焦点。筛选空态、校验、取消、失败恢复、暂停后保留本人已取得成果可见。不可分享资料须禁用并说明，不用提示词代替权限。

使用原生 HTML/CSS/JS，无CDN/网络素材/外部字体。index.html可双击打开，Logo可相对引用本地assets或dataURL。尽量可读分段，少于1000行。旧个人版已保存到 archive/personal-sharing-v0.html，仅作方向对照，明确非当前方案。
